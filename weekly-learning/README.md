# weekly-learning

> Every Saturday, a deep-dive exploration of a random topic delivered by email.

## Status

Planned — not yet implemented.

## What It Will Do

Picks a random topic, generates a deep exploration using an LLM, and emails it as a Saturday morning read.

## How It Will Run

- **Trigger:** GitHub Actions on a weekly cron schedule (Saturday)
- **Entry point:** `main.py`
- **Secrets:** See `.env.example` (created during implementation)
