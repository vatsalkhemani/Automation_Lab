# hiring-tracker

> Weekly pulse on which tech companies are scaling up or cutting back.

## Status

Planned — not yet implemented.

## What It Will Do

Aggregates hiring signals from job boards and news, synthesizes trends using an LLM, and delivers a weekly report by email.

## How It Will Run

- **Trigger:** GitHub Actions on a weekly cron schedule
- **Entry point:** `main.py`
- **Secrets:** See `.env.example` (created during implementation)
