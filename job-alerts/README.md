# job-alerts

> Daily filtered job openings delivered to your inbox.

## Status

Planned — not yet implemented.

## What It Will Do

Queries job boards with specific filters, formats matching openings, and sends a daily email digest.

## How It Will Run

- **Trigger:** GitHub Actions on a daily cron schedule
- **Entry point:** `main.py`
- **Secrets:** See `.env.example` (created during implementation)
