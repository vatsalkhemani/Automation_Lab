# ai-news-digest

> Daily email with concise AI news from the last 24 hours.

## Status

Planned — not yet implemented.

## What It Will Do

Pulls recent AI news from multiple sources, uses an LLM to summarize the most important stories into a concise digest, and sends it by email every morning.

## How It Will Run

- **Trigger:** GitHub Actions on a daily cron schedule
- **Entry point:** `main.py`
- **Secrets:** See `.env.example` (created during implementation)
