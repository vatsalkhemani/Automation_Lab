# gmail-declutter

> Weekly automated inbox cleanup.

## Status

Planned — not yet implemented.

## What It Will Do

Connects to Gmail via API, applies rules to archive, label, or delete emails, and runs weekly on a schedule.

## How It Will Run

- **Trigger:** GitHub Actions on a weekly cron schedule
- **Entry point:** `main.py`
- **Secrets:** See `.env.example` (created during implementation)
